# Sales Dashboard using Tableau

## Project Title
Sales Dashboard using Tableau

---

##  Project Overview
This project is an interactive **Sales Dashboard** developed using **Tableau** to analyze customer shopping and sales data. The dashboard provides meaningful business insights through visual analytics and KPI tracking.

The dashboard helps understand:
- Sales performance
- Customer purchasing behavior
- Payment method preferences
- Monthly sales trends
- Category-wise sales distribution
- Mall-wise sales comparison

This project demonstrates practical knowledge of:
- Data Visualization
- Business Intelligence
- Dashboard Designing
- Data Analytics using Tableau

---

##  Dashboard Features

###  Interactive Visualizations
- Treemap visualization for category-wise sales
- Pie charts for customer gender distribution
- Pie charts for payment methods
- Monthly sales trend line chart
- Shopping mall sales comparison bar chart

###  KPI Cards
- Total Sales
- Total Quantity
- Total Invoices
- Average Order Value (AOV)

###  User-Friendly Design
- Clean dashboard layout
- Organized visual structure
- Business-focused insights
- Easy-to-understand charts

##  KPIs Used

| KPI | Description |

##  Key Insights

- Clothing category generated the highest sales revenue.
- Female customers contributed more to total sales compared to male customers.
- Cash was the most preferred payment method.
- Mall of Istanbul recorded the highest sales among all shopping malls.
- Monthly sales showed fluctuations across the year.

## How to Use

1. Download the repository files.
2. Open the `.twb` or `.twbx` file using Tableau Desktop or Tableau Public.
3. Connect the dataset if required.
4. Explore the dashboard and interact with the visualizations.
